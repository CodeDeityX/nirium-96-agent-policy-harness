# R3 / 1dc5969 findings

R3 replaces the R2 external signer adapter with Nirium's official policy hook.
Target and commands are pinned in README and config/upstream.json. Installation
must not change the lock. Scope remains local agent-side pre-sign behavior.

Expected per platform: 56 Jest + 114 Node = 170 total; 34/35 strict R2
correspondence, 35/35 adapted assertions, zero skips, 50/50 supplementary.
G1-SELF-ESCALATION yields CONTEXT_MISMATCH before policy consultation, signer=0.
R2 historically expected engine consultation and DENY: that strict distinction
remains. Admin/account cases now use real x402Fetch with simulated RPC auth;
network-preimage alone uses an explicitly private gate boundary because the RPC
auth object cannot supply a separate networkId.

Seven independently verified fix findings: invalid clocks fail closed at every
read; SIGNED follows signer return; unusable signedAuthEntry gives SIGNER_ERROR;
observer clock, version and address changes are each caught by final checks;
rejected/pending observer promises are isolated without awaiting them.
L01 limitation (capacity reservation) and L02 limitation (same-process raw signer
access/method replacement) remain intentional. Neither was counted as fixed.

NO_EXISTING_R3_CASE_RETURNS_MISSING_SIGNEDAUTHENTRY

All 35 existing G1 IDs and eight original diagnostic IDs were audited. Every
returned result includes a nonempty string. Throws/no-calls are not returned
missing-field objects. Seven new invalid-result controls give
X402PolicyError/SIGNER_ERROR. Tampered nonempty signatures still give plain Error
from Stellar verification; signer failures give plain Error plus SIGNER_ERROR receipt.

Current outcomes: DENY/WAIT, ENGINE_ERROR, TIMEOUT (also freshness timeout),
UNBOUND, MALFORMED, EXPIRED (including missing expiry), STALE,
VERSION_UNAVAILABLE (error/empty), SIGNER_CHANGED, CLOCK_INVALID,
CONTEXT_MISMATCH and SIGNER_ERROR. ALLOWED is only a pre-final-check notice;
SIGNED is only a nonempty returned string, not downstream verification or settlement.
Policy/version/clock, merchant, RPC and Horizon are simulated; real installed
modules and cryptography run. No atomic freshness or account enforcement claim.
This is an independent review candidate, not Nirium endorsement or adoption.
